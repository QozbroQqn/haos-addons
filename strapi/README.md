# Strapi Home Assistant Add-on

A flexible Strapi 5 implementation for Home Assistant OS, designed for persistence, ease of customization, and developer access.

For detailed instructions on how to use and customize this add-on, please refer to the **Documentation** tab in the Home Assistant UI.

### 🛡️ Quick Overview

- **Persistent Code:** Edit your Strapi project files directly in your Home Assistant `/config/` directory
- **Project Location:** Strapi is installed in `/config`
- **SQLite Database:** Your data stays in your persistent `/config/` folder
